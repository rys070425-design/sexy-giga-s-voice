# 0.7 · 읽기 편한 자막

## 사용 방법

기존 앱을 닫고 0.7 설치 파일을 같은 위치에 실행하세요. 모델을 불필요하게 다시 받지 않고 설치 상태를 확인합니다.

- **표시 언어 / Captions**: 한국어 번역 또는 English captions를 선택합니다. 영어를 듣고 영어 자막을 보고 싶은 사용자는 음성 언어도 영어로 선택하세요. English captions는 영어 음성에 별도 번역 모델이 필요하지 않습니다. 모든 다른 언어를 영어로 번역하는 모델이 기본 제공되는 것은 아닙니다.
- **배경 진하기**: 프로필과 자막 화면에서 15~80% 조절합니다. 기본값42%는 기존 약90%보다 훨씬 투명합니다. 낮을수록 투명합니다. 재생 중에도 반영됩니다.
- **출처 이름**: 첫 화면에서 비워 두면 소리를 내는 Windows 앱을 감지합니다. YouTube 같은 이름을 직접 입력할 수도 있습니다.
- **웹사이트 이름 연결**: Chrome/Edge 확장을 한 번 연결하면 소리가 나는 탭의 도메인을 받아 YouTube, Twitch 또는 사이트 이름으로 표시합니다. 앱 버튼의 폴더 열기·연결 코드 복사 안내를 따르세요. 확장을 설치하지 않으면 Chrome/Edge 등 앱 이름까지 표시합니다. 음소거·시크릿 탭은 전달 대상에서 제외합니다.
- **Discord 현재 통화방 자동 연결**: 최초 공식 승인 후 체크해 두면 앱 재시작과 통화방 이동을 따라갑니다. 브라우저 Discord가 아닌 PC 앱을 사용하세요. 공식 API가 현재 채널 조회를 거부하면 저장된 링크 또는 수동 입력이 필요합니다.

## 가독성을 위해 정리한 동작

1. 외국어 초안 원문과 한국어 번역을 매번 교대로 덮어쓰던 동작을 없앴습니다. 언어와 글자 길이가 계속 바뀌는 깜빡임을 줄이기 위해서입니다. 사용자가 원문 표시를 켜면 별도 작은 줄로 볼 수 있습니다.
2. ‘화자 미확인 · 인식 중’을 영상 위에 반복해서 적지 않습니다. 출처 이름을 표시하고 상세 작동 상태는 앱 화면에서 확인합니다. 출처가 확인되지 않으면 ‘오디오’로 표시합니다.
3. 원문과 표시 문장이 같으면 똑같은 문장을 한 번 더 표시하지 않습니다. 영어 자막 모드와 한국어 음성에서 중복 공간을 줄입니다.
4. 전면에 열린 웹사이트를 소리 출처로 추측하는 기능은 넣지 않았습니다. 다른 탭이나 창에서 소리가 날 때 잘못된 이름을 붙일 수 있기 때문입니다.

## 검사 결과와 범위

2026-10-17 개발 환경에서 자동 검사 **79개**를 통과했습니다. 출처의 시점 정렬·여러 소리·오래된 브라우저 정보 만료, 첫 자막 추가 대기 없음, 빠른 수정 합치기, 이전 문장 유지, 오래된 번역 역전 방지, 로컬 연결 코드 및 요청 검사, 영어 모드에 한국어 보정이 잘못 적용되지 않는지 등을 검사했습니다.

별도 설치 환경에서 GPU Whisper 인식과 Argos 번역, 7개 화면, 두 줄 표시, 투명도 즉시 변경, 모의 Discord 현재 채널 조회·자동 주소 선택, 이전 WebSocket 종료, 모의 브라우저 API의 음소거/시크릿 필터와 호스트명만 전달하는 동작을 검사했습니다. 소리 출처 작업을 포함한 4개 작업의 인식→번역→정상 중지 시험도 통과했습니다.

실제 Windows 오디오 세션 조회를 실행해 정상 동작을 확인했습니다. Chrome/Edge 확장을 사용자의 브라우저에 설치하거나 Discord 계정 승인을 대신 수행한 것은 아닙니다. 실제 통화방 이동과 브라우저 사이트 식별 성공까지 개발 시험에서 확인했다고 주장하지 않습니다.

기본 음성 입력은 선택한 출력 장치 전체의 혼합 소리입니다. 여러 앱·여러 탭이 동시에 재생되면 단어마다 소리 출처를 분리할 수 없으며 여러 출처를 표시합니다. 두 줄은 번역문 기준이며 선택적으로 원문을 켜면 작은 원문 줄이 추가됩니다. 긴 문장은 최근 두 줄을 보여 주고 전체 확정 문장은 대화 기록에서 볼 수 있습니다.

기존 속도 시험은 0.6 검증 문서에 있으며, 0.7에서 모든 환경의 지연을 1.4초 이하로 보장하는 것은 아닙니다. 가독성 갱신 간격과 인식 속도는 별개입니다. 모델 가중치는 새로 학습하지 않았습니다.
