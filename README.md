# Universal Voice KR 0.9.3

Windows PC에서 Discord 등의 출력 소리를 받아 자막으로 보여 주는 앱입니다.
기본 음성 인식과 번역은 PC에서 처리하며 유료 API가 필요하지 않습니다. 기본 번역 모델은 무료 개인·비상업용(CC-BY-NC-4.0)입니다.

## Android 모바일

휴대폰 마이크로 주변 대화를 듣고 번역하는 별도의 Android 앱을 추가했습니다. [Android APK 받기](https://raw.githubusercontent.com/rys070425-design/sexy-giga-s-voice/main/dist/UniversalVoice_Android_v010.apk) · [설치와 사용 안내](mobile/README.md). PC 연결이나 Python이 필요하지 않습니다. 휴대폰 음성 서비스와 ML Kit 번역을 사용하며 Windows판과 모델·기능이 다릅니다.

## 설치

[Windows 설치 파일 받기](https://raw.githubusercontent.com/rys070425-design/sexy-giga-s-voice/main/dist/UniversalVoiceKR_Setup_v093.exe)

[공유용 설치 ZIP 받기](https://raw.githubusercontent.com/rys070425-design/sexy-giga-s-voice/main/dist/UniversalVoiceKR_v093_Windows_Installer.zip)

메신저에서 EXE 파일을 첨부할 수 없다면 설치 파일과 안내만 들어 있는 ZIP을 이용하거나 이 저장소 링크를 공유하세요. ZIP은 Windows PC에서 압축을 모두 풀고 안의 EXE를 실행합니다. 소스 ZIP과는 다릅니다. 휴대폰용 앱은 아닙니다. ZIP 내부 설치 파일의 무결성은 확인했지만 카카오톡 전송 성공을 직접 시험한 것은 아닙니다.

1. 기존 앱과 이전 설치 프로그램을 닫고 설치 파일을 실행합니다.
2. 영어로 시작하는 설치 창의 **Language**에서 언어를 고릅니다. 한국어를 고르면 안내가 즉시 한국어로 바뀝니다. 기존 설치와 같은 위치를 선택하면 받은 모델과 구성요소를 재사용합니다.
3. 설치 후 같은 언어가 앱 UI와 자막 언어에 적용됩니다. 재생 출력 장치를 선택하고 **자막 시작**을 누릅니다. 기본적으로 설정한 언어의 말은 자막과 기록에서 제외합니다.

최초 설치에는 인터넷 연결과 수 GB의 여유 공간이 필요합니다. Whisper large-v3-turbo, NLLB-200 distilled 600M 번역 모델, 약 28MB의 CAM++ 화자 보조 모델을 내려받는 온라인 설치 파일입니다. 번역 자료는 약 582MB이며 SHA-256을 확인합니다. 관리자 권한이나 시스템 PATH 변경 없이 사용자 계정에 설치합니다. NVIDIA GPU가 있으면 음성 인식에 GPU를 우선 사용하며 CPU도 선택할 수 있습니다.

## 0.9.3에서 바뀐 점

- 일반 대화의 첫 초안 시점을 유지하고 최종 인식 문맥을 8초에서 10초로 늘렸습니다. 실제 억양 녹음 한 개의 단어 오류율은 10.14%에서 8.70%로 줄었고, 다른 한 개는 4.35%를 유지했습니다. 두 읽기 녹음의 제한된 비교입니다.
- 뜻이 명확한 일부 영어 축약형을 번역 전에 풀어 미래·비교 표현의 일부 의미 오류를 줄입니다. 인식 원문은 유지합니다.
- 약 28 MB의 **CAM++ 목소리 보조 모델**을 추가했습니다. Discord의 확실한 단독 발언으로 현재 통화방의 닉네임을 연결한 뒤, 충분한 증거가 있을 때만 불확실한 이름을 보완합니다. 이름 확인 때문에 자막을 기다리게 하지 않습니다.
- 목소리 정보는 메모리에만 두고 통화방 변경·중지 시 폐기합니다. 겹친 음성을 사람별로 분리하거나 처음 듣는 목소리의 실명을 알아내는 기능은 아닙니다.

## 이전 버전의 기반 기능

0.6.1에서는 Discord 통화방의 일반 채널 링크도 자동으로 처리합니다. 승인 대기·승인 실패·통화방 정보 읽기 실패를 구분해서 표시하며, **닉네임 연결 없이 자막 시작** 버튼을 추가했습니다. [연결 수정 안내](docs/discord-connection-v061.md)

- 문장이 끝나기 전에도 약 0.5초 분량부터 임시 자막을 표시하고, 문장이 끝나면 선택한 인식 정밀도로 다시 확인합니다. GPU에서는 이후 약 0.4초 간격으로 새 초안을 준비합니다. CPU는 처리량을 고려해 간격을 늘립니다. 실제 표시 시간에는 처리 시간이 추가됩니다.
- 선택한 언어로 번역하거나 원문 자막을 표시합니다. 번역을 기다리는 짧은 외국어 원문으로 화면이 번쩍 바뀌지 않도록 했습니다.
- 번역이 늦어도 이전 문장이 최신 자막을 덮지 않습니다. 임시 문장은 대화 기록에 중복 저장하지 않습니다.
- 말을 다 마치거나 침묵하기를 기다리지 않고 같은 자막창을 계속 갱신합니다. 첫 문장 전에 인식 모델과 번역 모델을 준비합니다.
- 첫 화면에 음성 언어 선택을 추가했습니다. 프로필의 **인식할 이름·용어**에 자주 틀리는 닉네임과 게임 용어를 선택적으로 등록할 수 있습니다.
- 0.5.1에서 설치 내역 창을 닫으면 발생하던 TextBox 오류 수정도 포함합니다.

음성 모델은 **Whisper large-v3-turbo / faster-whisper**이며 기본 확정 인식은 beam 5입니다. 모델 가중치를 새로 학습한 버전은 아닙니다. 임시 인식은 빠르게 표시하기 위한 초안이므로 문장이 끝날 때 수정될 수 있습니다. [시험 조건과 결과](docs/validation-v060.md)를 확인하세요.

## Discord 닉네임 연결

앱의 **Discord 연결**에서 본인 계정으로 공식 Streamkit 연결을 승인하고 음성 채널 위젯 주소를 지정합니다. 봇 초대는 필요하지 않습니다. 공개 위젯의 말하는 사람 표시와 출력 소리의 시점을 연결하는 방식입니다. 여러 사람이 동시에 말하면 각 사람의 음성을 정확하게 분리할 수 없습니다. 실제 Discord 통화 연결은 사용자의 승인이 필요하며, 개발 검사는 녹음 입력과 위젯 모의 화면으로 진행했습니다.

## 정확도를 높이는 설정

같은 언어 숨김을 켜면 음성 언어는 자동 감지로 동작합니다. 매우 짧은 말에서는 언어를 잘못 알아볼 수 있습니다. 한 외국어만 듣고 인식 언어를 고정하려면 같은 언어 숨김을 먼저 끄고 **음성 언어**를 고르세요. 정확한 실제 이름과 용어만 등록하세요. 어려운 발음은 더 큰 `large-v3` 모델을 선택해 비교할 수 있지만 처리량과 메모리 사용이 늘고 첫 선택 시 추가 다운로드가 필요합니다.

NLLB 번역에도 오역이 남아 있습니다. 음성 인식 정확도와 번역 품질은 별개입니다. 선택 기능인 ChatGPT 문장 보정은 별도 로그인과 계정 이용 조건이 적용되며 실시간 기본 자막에 필수적이지 않습니다.

## 소스 실행 및 설치 파일 빌드

- `app/`: 앱 소스와 회귀 검사
- `installer/`: Windows 설치 프로그램 및 구성요소 준비 스크립트
- `dist/`: 설치 EXE 및 SHA-256
- `tools/`: 설치 검증 도구
- `docs/`: 시험 결과

Windows 64비트 Python 3.11과 `app/requirements-install.txt`의 패키지가 필요합니다. 별도 가상환경을 만든 뒤 `app/prepare_runtime.py`로 모델을 준비하고 `app/launch.py`로 실행합니다. GPU 사용 시 설치 프로그램이 준비하는 NVIDIA 패키지도 필요합니다.

PowerShell에서 설치 파일을 다시 만들려면 다음을 실행합니다. Windows 기본 .NET Framework C# 컴파일러를 사용합니다.

```powershell
.\installer\Build.ps1
```

검사는 앱 환경의 Python으로 저장소 루트에서 실행합니다.

```powershell
$env:PYTHONPATH = (Resolve-Path .\app).Path
python -B -m unittest discover -s app\tests -v
```

자격증명, 실제 대화 녹음, 내려받은 모델 및 가상환경은 저장소에 포함하지 않습니다. 외부 구성요소의 출처와 라이선스는 [외부 구성요소 안내](docs/third-party.md)에 정리했습니다.
