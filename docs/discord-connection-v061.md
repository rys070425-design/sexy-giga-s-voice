# Discord 연결 수정 · 0.6.1

## 연결 방법

1. Discord **PC 앱**에서 통화방에 들어갑니다.
2. 앱의 **Discord 연결 → 공식 연결 화면 열기**를 누릅니다. 공식 화면의 **Install for OBS** 버튼을 누르고 Discord가 띄운 연결 승인 창을 직접 승인합니다.
3. Discord에서 현재 통화방을 우클릭하여 **채널 링크 복사**를 선택합니다.
4. 그 링크를 앱에 붙여넣고 **닉네임 연결 시작**을 누릅니다. 일반 `https://discord.com/channels/서버ID/채널ID` 형식을 자동으로 공식 Voice Widget 주소로 바꿉니다.

OBS 설치나 서버 봇 초대는 이 연결에 필요하지 않습니다. 개인 메시지·그룹 통화·초대 링크는 이 서버 음성 채널 위젯 입력에 사용할 수 없습니다.

음성 자막만 사용하려면 **닉네임 연결 없이 자막 시작**을 누르세요. 출력 소리 인식에는 Discord 연결 승인이 필요하지 않으며 화자는 미확인으로 표시됩니다.

## 수정 내용과 검증 범위

- 이전 입력칸은 공식 위젯 주소만 허용하여 일반 채널 링크를 넣으면 연결을 시작하지 못했습니다. 일반 채널 링크도 받아 자동 변환하고 입력칸에 실제 위젯 주소를 표시합니다.
- WebSocket 접속만으로 연결 완료로 보이던 상태 표시를 수정했습니다. 공식 페이지가 받은 승인·채널 조회 응답을 구분해 **승인 대기 / 승인 실패 / 채널 읽기 실패 / 연결 완료**를 표시합니다.
- 초대 생성 응답은 닉네임 연결 완료 조건에 포함하지 않습니다. 서버 초대 생성 권한 오류를 채널 조회 성공과 혼동하지 않는지 모의 응답으로 검사합니다.
- 연결 관찰은 명령 이름·승인 성공 여부·숫자 오류 코드만 보관합니다. 토큰·승인 코드·메시지 내용·전체 응답은 기록하지 않습니다.
- 일반 채널 링크와 잘못된 링크, 미승인 접속, 권한 오류, 채널 조회 완료를 포함한 자동 검사 58개를 통과했습니다. 추가로 WebEngine에서 모의 WebSocket 응답과 새 연결 후 이전 연결 종료 처리를 검사합니다.

실제 Discord 연결 승인은 사용자가 직접 완료해야 합니다. 이 수정의 통화 검증은 모의 응답 검사이며, 사용자의 계정과 실제 통화방에서 닉네임 연결 성공까지 대신 승인하거나 확인한 것은 아닙니다.
