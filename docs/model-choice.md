# 모델을 크게 바꾸기 전에 비교한 결과

기본 음성 인식은 **large-v3-turbo**, NVIDIA GPU 우선으로 유지합니다. 더 큰 large-v3를 실제로 받아 비교했지만 이 작은 스트리밍 시험에서 항상 더 정확하지는 않았습니다. GPU가 없는 환경의 small도 더 빨랐지만 1.4초 목표를 달성하지 못했습니다. 모델 크기만 보고 자동 교체하지 않은 이유입니다.

## 0.8.1 분할 조건에서의 모델 비교

Windows / RTX 4050 Laptop 6GB / Intel i7-13700H, faster-whisper 1.2.1, CTranslate2 4.8.3, GPU int8_float16 / CPU int8·4스레드를 사용했습니다. 번역은 NLLB CPU int8입니다. 각 조건 1회이며 모델 준비 시간은 제외했습니다.

| 음성 모델 / 장치 | 합성 입력 7조건 첫 Qt 렌더링 범위 | korean1 WER | spanish1 WER |
|---|---:|---:|---:|
| large-v3-turbo / GPU | 0.781~1.250초 | 17.39% | 4.35% |
| large-v3 / GPU | 0.860~1.266초 | 17.39% | 10.14% |
| small / CPU | 2.609~6.875초 | 18.84% | 5.80% |
| large-v3-turbo / CPU | 7.391~13.656초 | 미측정 | 미측정 |

첫 렌더링은 자체 합성 음성의 영어·한국어, 언어 고정·자동, 빠른 말·잡음·영어 원문 표시 조건을 포함합니다. WER는 별도의 [Speech Accent Archive](https://accent.gmu.edu/) 읽기 녹음 두 개를 전체 인식·번역 파이프라인에 실제 시간으로 공급해 얻었습니다. 앞의 합성 입력 시간과 같은 시험 지표가 아닙니다.

WER 계산은 대소문자와 문장부호를 정리해 단어를 비교하며 숫자 표기를 통일하지 않습니다. 따라서 숫자와 영어 수사의 표기 차이도 오류로 셉니다. 이 수치만으로 번역의 의미 정확도를 판단하거나 모든 억양에서 특정 모델이 우월하다고 말할 수 없습니다. 두 실제 녹음 모두 모든 모델에서 대기열 초과 없이 작업이 끝났지만 인식·번역 오류는 남았습니다.

큰 모델의 원본은 [Systran의 CTranslate2 large-v3](https://huggingface.co/Systran/faster-whisper-large-v3), revision `edaa852ec7e145841d8ffdb056a99866b5f0a478`입니다. 비교에 쓴 model.bin은 3,087,284,237바이트, SHA-256 `69f74147e3334731bc3a76048724833325d2ec74642fb52620eda87352e3d4f1`입니다. 앱 기본 설치에 이 추가 모델을 강제로 넣지 않았습니다. 큰 모델의 게임 동시 실행 메모리 여유는 보장하지 않습니다.

## 실제 선택 방법

- 일상 통화·게임: **large-v3-turbo**, **자동 · GPU 우선**, 실제 주 사용 **음성 언어**를 먼저 선택하세요. 영어 대화라면 English로 고정하는 것이 좋은 출발점입니다.
- 영어가 자주 끊기거나 주저하는 대화·영상: 0.8.2의 **일반 대화 · 문장 문맥 유지**를 사용하세요. 음성 모델을 늘리는 대신 확정 문장의 문맥을 조금 더 유지합니다. 첫 초안은 계속 먼저 보여 줍니다.
- 다른 억양에서 큰 모델을 비교하고 싶다면 프로필의 **large-v3 · 정확도 우선 / 부하 큼**을 직접 선택할 수 있습니다. 처음 선택하면 별도 대용량 다운로드가 필요하고, 더 정확하다는 보장은 없습니다.
- GPU 없이 **small**을 선택하면 이 CPU 시험에서는 대기가 짧아졌지만 인식 오류가 조금 늘었습니다. 큰 모델을 CPU로 실행하는 것보다 실용적일 수 있으나 실시간 1.4초 대안으로 안내하지는 않습니다.

0.8.2 일반 대화 모드의 문맥 유지 변경과 새 검증 결과는 [0.8.2 안내](validation-v082.md)를 참고하세요. 위 표는 변경 전 0.8.1 조건의 비교 기록입니다. 실제 대화의 인식 정확도는 원문을 함께 보며 판단하세요. 기본 NLLB 번역 모델의 **CC-BY-NC-4.0 비상업용** 조건도 그대로 적용됩니다.
