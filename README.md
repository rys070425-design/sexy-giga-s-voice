# Universal Voice KR 0.8.2

Windows PC에서 Discord 등의 출력 소리를 받아 자막으로 보여 주는 앱입니다.
기본 음성 인식과 번역은 PC에서 처리하며 유료 API가 필요하지 않습니다. 기본 번역 모델은 무료 개인·비상업용(CC-BY-NC-4.0)입니다.

## 설치

[Windows 설치 파일 받기](https://github.com/rys070425-design/sexy-giga-s-voice/raw/refs/heads/main/dist/UniversalVoiceKR_Setup_v082.exe)

1. 기존 앱과 이전 설치 프로그램을 닫고 설치 파일을 실행합니다.
2. 기존 0.5 설치를 사용했다면 같은 위치를 선택합니다. 이미 받은 모델과 구성요소를 확인하여 이어서 준비합니다.
3. 설치가 끝나면 앱에서 Discord의 출력 장치와 주로 사용하는 **음성 언어**를 선택하고 **자막 시작**을 누릅니다.

최초 설치에는 인터넷 연결과 수 GB의 여유 공간이 필요합니다. Whisper large-v3-turbo와 NLLB-200 distilled 600M 번역 모델을 내려받는 온라인 설치 파일입니다. 번역 자료는 약 582MB이며 SHA-256을 확인합니다. 관리자 권한이나 시스템 PATH 변경 없이 사용자 계정에 설치합니다. NVIDIA GPU가 있으면 음성 인식에 GPU를 우선 사용하며 CPU도 선택할 수 있습니다.

## 0.8.2에서 바뀐 점

- 일반 대화의 짧은 머뭇거림을 너무 빨리 문장 끝으로 처리하던 부분을 고쳤습니다. 첫 초안은 계속 먼저 표시하며 게임 대화의 짧은 호출 간격은 유지합니다.
- 실제 영어 억양 녹음 두 개의 전체 흐름 검사에서 WER는 각각 17.39%→10.14%, 4.35%→4.35%였습니다. 작은 시험이며 번역 정확도나 모든 억양의 보장은 아닙니다.
- 새 일상 문장과 빠르고 먹먹한 변형 입력에서 오류 증가가 없었고, 새 일반 대화 모드의 GPU 합성 입력 7조건 첫 Qt 렌더링은 0.781~1.250초였습니다. 모든 실제 통화의 1.4초 보장은 아닙니다.
- 94개 회귀 검사와 실제 설치 파일·GPU 인식·NLLB 번역·화면 검사를 통과했습니다.

## 0.8.1에서 바뀐 점

- 기본 번역에 쓰지 않는 Argos·Torch·Stanza 등의 중복 설치를 제거했습니다. 같은 PC의 새 설치 가상환경은 모델 파일을 제외하고 약 849MiB 작아졌습니다. 기존 언어 팩은 삭제하지 않습니다.
- 사이트 이름 연결 코드를 가려 표시하고 복사 버튼으로 연결합니다.
- 해당 구성요소가 없는 새 설치에서 91개 회귀 검사와 실제 GPU 인식·NLLB 번역·화면 검사를 통과했습니다.
- 별도 i7-13700H CPU 시험은 첫 초안 7.4~13.7초로 1.4초 목표를 달성하지 못했습니다. 실시간 대화에는 NVIDIA GPU 우선과 음성 언어 고정을 권장합니다.

## 0.8에서 바뀐 점

- 기본 번역을 NLLB-200 distilled 600M CPU int8로 교체했습니다. 실제 비교에서 발견한 부정문·일반 문장 오역을 줄였습니다. 음성 인식 모델은 Whisper large-v3-turbo를 유지합니다.
- 한국어·English·Español·Français·Deutsch·日本語·中文·Português 표시 언어를 선택할 수 있습니다. 영어를 듣고 자신의 언어로 읽거나 영어 원문 자막을 볼 수 있습니다.
- 실제 시간으로 공급한 합성 음성 7개 조건에서 첫 Qt 자막 렌더링이 0.781~1.250초였습니다. 빠른 영어·잡음·자동 감지를 포함하며, 실제 모든 통화의 1.4초 보장은 아닙니다.
- 이전 줄의 늦은 확정 수정, 투명도·출처 자동 저장, 중복 앱 실행 방지, 작은 창의 안내 줄바꿈을 보완했습니다.
- 원문과 번역을 복습할 수 있도록 현재 남아 있는 대화 기록의 수동 텍스트 저장을 추가했습니다. 음성이나 대화를 자동으로 저장하지 않습니다.

## 0.7에서 바뀐 점

- 인식 결과를 화면에 바로 덮어쓰는 대신 약 0.8초 간격으로 최신 번역을 반영합니다. 첫 번역은 추가 대기 없이 표시합니다.
- 이전 문장과 새 문장을 두 줄로 표시하고, 이전 문장은 잠시 유지합니다. 긴 문장은 화면 폭에 맞춰 최근 두 줄을 보여 줍니다.
- 자막 배경 진하기 기본값을 42%로 낮췄습니다. 프로필에서 15~80%로 즉시 조절할 수 있으며 글자 그림자로 대비를 유지합니다.
- 영상 위의 ‘화자 미확인 · 인식 중’을 재생 출처 이름으로 바꿉니다. Windows 재생 앱은 자동으로 감지하고, 정확한 웹사이트 이름은 선택적 Chrome/Edge 확장으로 연결합니다. 직접 YouTube 등 이름을 입력할 수도 있습니다.
- Discord 최초 승인 후 **현재 통화방 자동 연결**을 켜면 채널 이동과 앱 재시작을 따라갑니다. 공식 자동 조회가 허용되지 않으면 저장한 주소나 수동 연결로 돌아갑니다.
- **English captions** 모드를 추가했습니다. 영어 영상을 영어 자막으로 읽을 수 있으며 한국어 번역은 선택할 때만 적용합니다.

## 이전 버전의 기반 기능

0.6.1에서는 Discord 통화방의 일반 채널 링크도 자동으로 처리합니다. 승인 대기·승인 실패·통화방 정보 읽기 실패를 구분해서 표시하며, **닉네임 연결 없이 자막 시작** 버튼을 추가했습니다. [연결 수정 안내](docs/discord-connection-v061.md)

- 문장이 끝나기 전에도 약 0.5초 분량부터 임시 자막을 표시하고, 문장이 끝나면 선택한 인식 정밀도로 다시 확인합니다. GPU에서는 이후 약 0.4초 간격으로 새 초안을 준비합니다. CPU는 처리량을 고려해 간격을 늘립니다. 실제 표시 시간에는 처리 시간이 추가됩니다.
- 선택한 언어로 번역하거나 원문 자막을 표시합니다. 번역을 기다리는 짧은 외국어 원문으로 화면이 번쩍 바뀌지 않도록 했습니다.
- 번역이 늦어도 이전 문장이 최신 자막을 덮지 않습니다. 임시 문장은 대화 기록에 중복 저장하지 않습니다.
- 말을 다 마치거나 침묵하기를 기다리지 않고 같은 자막창을 계속 갱신합니다. 첫 문장 전에 인식 모델과 번역 모델을 준비합니다.
- 첫 화면에 음성 언어 선택을 추가했습니다. 프로필의 **인식할 이름·용어**에 자주 틀리는 닉네임과 게임 용어를 선택적으로 등록할 수 있습니다.
- 0.5.1에서 설치 내역 창을 닫으면 발생하던 TextBox 오류 수정도 포함합니다.

음성 모델은 **Whisper large-v3-turbo / faster-whisper**이며 기본 확정 인식은 beam 5입니다. 모델 가중치를 새로 학습한 버전은 아닙니다. 임시 인식은 빠르게 표시하기 위한 초안이므로 문장이 끝날 때 수정될 수 있습니다. [시험 조건과 결과](docs/validation-v060.md)를 확인하세요.

## Discord 닉네임 연결

앱의 **Discord 연결**에서 본인 계정으로 공식 Streamkit 연결을 승인하고 음성 채널 위젯 주소를 지정합니다. 봇 초대는 필요하지 않습니다. 공개 위젯의 말하는 사람 표시와 출력 소리의 시점을 연결하는 방식입니다. 여러 사람이 동시에 말하면 각 사람의 음성을 정확하게 분리할 수 없습니다. 실제 Discord 통화 연결은 사용자의 승인이 필요하며, 개발 검사는 녹음 입력과 위젯 모의 화면으로 진행했습니다.

## 정확도를 높이는 설정

주로 한 언어로 대화한다면 자동 감지 대신 해당 **음성 언어**를 선택하세요. 매우 짧은 말의 언어 오인식을 줄이고 매번 언어를 추정하는 비용을 줄일 수 있습니다. 정확한 실제 이름과 용어만 등록하세요. 어려운 발음은 더 큰 `large-v3` 모델을 선택해 비교할 수 있지만 처리량과 메모리 사용이 늘고 첫 선택 시 추가 다운로드가 필요합니다.

NLLB 번역에도 오역이 남아 있습니다. 음성 인식 정확도와 번역 품질은 별개입니다. 선택 기능인 ChatGPT 문장 보정은 별도 로그인과 계정 이용 조건이 적용되며 실시간 기본 자막에 필수적이지 않습니다.

## 소스 실행 및 설치 파일 빌드

- `app/`: 앱 소스와 회귀 검사
- `installer/`: Windows 설치 프로그램 및 구성요소 준비 스크립트
- `dist/`: 설치 EXE 및 SHA-256
- `tools/`: 설치 검증 도구
- `docs/`: 시험 결과

Windows 64비트 Python 3.11과 `app/requirements-install.txt`의 패키지가 필요합니다. 별도 가상환경을 만든 뒤 `app/prepare_runtime.py`로 모델을 준비하고 `app/launch.py`로 실행합니다. GPU 사용 시 설치 프로그램이 준비하는 NVIDIA 패키지도 필요합니다.

PowerShell에서 설치 파일을 다시 만들려면 다음을 실행합니다. Windows 기본 .NET Framework C# 컴파일러를 사용합니다.

```powershell
.\installer\Build.ps1
```

검사는 앱 환경의 Python으로 저장소 루트에서 실행합니다.

```powershell
$env:PYTHONPATH = (Resolve-Path .\app).Path
python -B -m unittest discover -s app\tests -v
```

자격증명, 실제 대화 녹음, 내려받은 모델 및 가상환경은 저장소에 포함하지 않습니다. 외부 구성요소의 출처와 라이선스는 [외부 구성요소 안내](docs/third-party.md)에 정리했습니다.
