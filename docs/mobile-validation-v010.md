# Android 0.1.0 검증

Android 휴대폰 마이크로 주변 대화를 듣고 번역 자막을 표시하는 별도 앱입니다. Windows 0.9.3은 변경하지 않았습니다. 배포 파일은 `dist/UniversalVoice_Android_v010.apk`입니다.

## 확인한 결과

- Java/Robolectric 자동 검사 **23개 통과**: 임시·확정 자막 순서, 이전 문장 보정, 최신 초안 합치기, 번역 대기열 제한, 캐시에서 같은 문장을 다시 표시, 오래된 결과 무시, 마이크 중지·재시작 취소, 권한 오류·반복 오류, 앱을 벗어난 뒤 자동 재시작 방지, 한국어/영어 화면 등.
- Android 35 x86_64 가상 기기에서 실제 설치와 실행 성공. 테스트 창과 PC 오디오·마이크를 사용하지 않았습니다.
- 최종 앱에서 실제 ML Kit 영한 번역팩 준비 및 예문 6개 번역 성공. 영어→한국어 5개, 한국어→영어 1개입니다. 자동화는 비어 있지 않은 결과와 정상 완료를 확인하며, 사람이 의미도 살폈습니다. 일반 정확도 점수를 뜻하지 않습니다.
- 기본 411dp 밝은 화면 및 360dp 작은 화면·시스템 글씨 130%·어두운 테마에서 한국어/영어 화면 검사 성공. 최신 자막 최소 두 줄과 시작·중지 버튼의 표시 영역을 확인했습니다. 화면 캡처의 자막은 **개발자가 작성한 화면 검사용 문장**입니다.
- Debug 및 Release lint **오류 0개, 경고 8개**. 경고는 고정한 라이브러리/도구의 최신 버전 안내와 `allowBackup` 사용 중단 안내입니다. 백업·기기 이전 제외 규칙을 별도로 포함했습니다.
- 배포용 APK에 RSA 3072 비공개 키로 서명하고 Android APK v2 서명 검증 통과. ARM64, ARMv7, x86, x86_64 포함. 디버그 시험 앱을 제거한 뒤 최종 서명 APK를 새로 설치해 첫 실행·활성 화면·프로세스 유지를 확인했습니다. 첫 실행에서 마이크 권한은 부여되지 않았으며 자동으로 듣지 않습니다.

## 실제 번역 결과와 한계

`I do not eat peanuts.` → `나는 땅콩을 먹지 않는다.` 처럼 부정 의미를 유지했고, 지하철 위치·도착 후 전화·예상보다 비싸다는 예문의 주요 의미도 유지했습니다. `조금 천천히 말해 주세요.` → `Please tell me a little slow.` 는 뜻은 짐작할 수 있지만 자연스럽지 않습니다. 정답 문장을 코드에 넣어 덮어쓰지 않았습니다.

영어 예문 5개의 준비 후 번역 계산 시간은 증거 JSON에 기록했습니다. 이것은 가상 기기에서 **이미 인식된 텍스트를 번역한 시간**으로, 음성 시작부터 자막 표시까지의 지연이 아닙니다. 휴대폰에서 1.4초 이내를 보장하는 자료로 사용하면 안 됩니다.

**실제 갤럭시 마이크로 발음·소음·멀리서 말하기·동시 발화·장시간 대화를 시험한 것은 아닙니다.** ARM 실기기 성능·발열·배터리도 아직 측정하지 않았습니다. 서비스 콜백 시험은 음성 인식 정확도 시험이 아닙니다. 음성 서비스의 부분 결과 주기와 연속 세션 사이 간격에 따라 지연·누락이 생길 수 있습니다.

## 발견하여 고친 점

1. Android 13 이전에서 개인정보 안내를 읽을 때 호환되지 않는 파일 읽기 API를 발견해 교체했습니다.
2. 언어를 변경하거나 앱을 벗어난 뒤 늦은 음성/번역 결과가 새 화면을 덮지 않도록 세션을 구분했습니다. 중지하면 예약된 재시작도 취소합니다.
3. 작은 화면과 큰 글씨에서 이전 문장 때문에 새 자막이 화면 아래로 밀렸습니다. 새 문장 시작 때만 읽을 영역으로 이동하게 고쳤습니다. 임시 결과마다 화면을 움직이지 않습니다. 긴 언어 이름의 버튼은 높이가 늘어나게 했습니다.
4. 대화 텍스트를 Android 뷰 상태로 저장하지 않게 했으며, 설정과 모델만 유지합니다. 사용자의 녹음·텍스트·목소리 프로필을 자동 저장하는 기능을 넣지 않았습니다.

## 범위와 선택

기본은 지원되는 Android 기기 내 음성 인식, 번역은 ML Kit 기기 내 번역입니다. 기본 모드를 사용할 수 없을 때 자동으로 네트워크 음성 서비스로 넘기지 않습니다. 사용자가 설정에서 전송 가능성 안내를 확인한 경우에만 휴대폰 기본 서비스를 선택합니다.

모바일은 입력 언어를 직접 고릅니다. 자동 언어 판별/같은 언어 숨김/Discord 연결/닉네임·목소리 구분을 이번 버전에 추가하지 않았습니다. 주변 대화 번역에 필요한 마이크·언어·큰 자막부터 검증하려는 선택입니다. Windows판의 기존 기능을 제거한 것은 아닙니다.

원문 표시/더 큰 글씨/화면 유지/자막 지우기만 추가했습니다. 광고, 유료 API 연결, 자동 녹음, 백그라운드 마이크, 대화 내보내기는 포함하지 않았습니다.
