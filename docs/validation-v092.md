# Universal Voice KR 0.9.2 — Discord 닉네임: 내용

[설치 파일](https://raw.githubusercontent.com/rys070425-design/sexy-giga-s-voice/main/dist/UniversalVoiceKR_Setup_v092.exe) · [공유용 설치 ZIP](https://raw.githubusercontent.com/rys070425-design/sexy-giga-s-voice/main/dist/UniversalVoiceKR_v092_Windows_Installer.zip)

Discord의 말하는 사람 표시를 자막의 발언 시각에 대응하여 **닉네임: 내용**으로 표시합니다. 이전에도 같은 표시를 참고했지만, 표시가 약 0.08초 겹치면 바로 긴 ‘동시 발화’ 이름표를 붙여 읽기 불편했습니다.

## 표시 방식

```text
민수: 여기서 기다려 주세요.
철수: 제가 갈게요.
```

- 확인된 Discord 화자는 별도의 ‘Discord · 닉네임’ 머리글 대신 자막 본문에 `닉네임: 내용`으로 표시합니다.
- 화자가 바뀌면 이전 문장의 닉네임은 이전 문장에 남고 새 문장에는 새 닉네임이 붙습니다.
- 같은 사람의 단독 발언이 앞뒤에 확인되는 짧은 표시 겹침은 이어서 처리합니다. 실제 화자가 바뀌는 경계에서는 한 사람을 임의로 고르지 않습니다.
- ‘동시 발화’ 상태 문구를 자동으로 붙이지 않습니다. 둘의 표시가 계속 켜져 있으면 `민수 / 철수: 내용`처럼 함께 확인된 이름을 표시합니다.
- 긴 자막과 긴 닉네임에서도 현재 두 줄 읽기 창에 닉네임을 남깁니다. 화면에 너무 긴 닉네임은 줄여 보이지만 원래 이름 데이터는 유지합니다.

## 필요한 연결과 한계

Discord 닉네임 연결이 정상이어야 합니다. 최초 공식 Streamkit 연결 승인은 사용자가 완료해야 하며 서버 봇 초대는 필요하지 않습니다. 데스크톱 화면을 이미지로 훔쳐보거나 계정 토큰을 가져오는 방식이 아니라, 기존 공식 Voice Widget의 말하는 사람 표시를 읽습니다.

실제 음성은 PC 출력에 섞여 들어옵니다. 말하는 사람 표시가 둘 다 켜져 있으면 어떤 인식 단어가 어느 사람의 것인지 확정할 수 없습니다. 이름을 묶어 표시하는 것이며, 두 사람의 음성을 각각 분리하여 독립적인 두 문장으로 만든 기능은 아닙니다. 녹색 표시의 유지 시간·네트워크·짧은 반응·겹친 말에 따라 이름 추정이 틀릴 수 있습니다.

단독 발언의 짧은 표시 겹침 보정은 추정입니다. 짧은 겹침을 모두 정확히 구분하는 학습된 화자 분리 모델이 아닙니다. 여러 사람이 차례로 말한 긴 초안에 처음 사람 이름을 통째로 붙이지 않으며, 확정 인식의 단어 시각으로 화자별 문장을 나눕니다.

0.9.1의 출처 확인도 유지합니다. 재생 출처가 YouTube이거나 불확실할 때 Discord 활동만 보고 Discord 닉네임을 붙이지 않습니다. 브라우저 Discord의 공식 도메인도 이름 연결에 사용할 수 있습니다. 여러 재생 앱이 겹치거나 음성이 너무 조용하면 이름 없는 자막이 나올 수 있습니다.

## 검증

- **112개 회귀 검사 통과**: 단독 화자, 100ms의 짧은 표시 겹침, 진짜 화자 전환 경계, 지속적인 겹침, 끊긴 위젯, 단어별 화자 분할, 다른 앱에 닉네임을 잘못 붙이지 않음 등을 확인했습니다.
- 실제 Qt 화면에서 `민수: …` 다음 `철수: …`, 이전 줄의 이름 유지, `민수 / 철수: …`, 긴 닉네임과 긴 자막을 확인했습니다. 언어 설정 25개 선택지·같은 언어 숨김·출처가 불분명할 때 헤더 숨김도 검사했습니다.
- 실제 새 EXE를 독립 시험 폴더에 설치하고 Whisper GPU 인식·NLLB 번역·기존 화면 및 Discord 모의 연동 검사를 수행했습니다.
- 직접 만든 영어 음성을 실제 Whisper 단어 시각과 NLLB 번역에 통과시킨 뒤, 제어된 Discord 발언 표시 타임라인 4조건(단독·짧은 겹침·화자 전환·지속 겹침)에 대응하여 자막 렌더링까지 확인했습니다. [수치 증거](evidence/discord-speaker-pipeline-v092.json)

이 시험은 실제 음성 모델과 제어된 발언 표시를 결합한 검사입니다. 사용자 계정의 실제 Discord 다중 사용자 통화를 끝까지 검증한 것은 아닙니다. ASR가 잘못 들은 문장과 번역 오류를 화자 표시가 해결하지는 않습니다. [화면 검사 증거](evidence/discord-inline-ui-v092.json)

기존 앱을 닫고 같은 위치에 설치하면 모델을 재사용합니다. 최초 온라인 설치에는 인터넷과 수 GB 공간이 필요합니다. Windows PC용이며, Whisper large-v3-turbo와 개인·비상업용 NLLB(CC-BY-NC-4.0) 모델을 사용합니다.
