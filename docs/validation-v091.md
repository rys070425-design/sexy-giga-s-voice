# Universal Voice KR 0.9.1 — 재생 출처 표시 수정

[새 설치 파일](https://raw.githubusercontent.com/rys070425-design/sexy-giga-s-voice/main/dist/UniversalVoiceKR_Setup_v091.exe)

이전에는 프로그램 자신의 소리 수집용 Python 세션을 출처 후보에서 따로 제외하지 않았습니다. 또한 한 음성 구간에서 발견한 여러 앱과 사이트 이름을 합쳐 나열하고, 모르는 프로그램도 실행 파일 이름으로 표시했습니다. 이 때문에 실제 발화의 출처를 이해하기 어려웠습니다.

## 달라진 표시

| 상황 | 표시 |
|---|---|
| 앱이 켜져 있지만 재생 소리가 없거나 음소거됨 | 출처 후보에서 제외 |
| 이 앱 자신의 Python·보조 프로세스 | 출처 후보에서 제외 |
| YouTube가 재생되고 출처가 일관되게 확인됨 | YouTube |
| Discord만 재생되고 공식 닉네임 활동도 연결됨 | Discord · 닉네임 |
| Discord와 YouTube가 계속 함께 재생됨 | 이름 없이 자막만 표시 |
| 여러 브라우저 사이트가 동시에 재생됨 | 사이트를 나열하지 않고 브라우저 이름만 표시 |
| 모르는 프로그램·Python 등 실행 파일 이름만 있음 | 이름 없이 자막만 표시 |

출처가 불확실할 때는 작은 출처 줄 자체를 숨깁니다. 이전 문장의 출처는 해당 이전 문장에만 붙이고 새 문장의 출처로 넘기지 않습니다. Discord 활동만 보고 다른 재생 소리를 Discord 닉네임으로 추정하지 않습니다. 사용자가 직접 입력한 출처 이름은 명시적인 설정으로 유지합니다.

Windows 재생 세션의 활성 상태·음소거·볼륨·순간 소리 크기를 함께 확인합니다. 기존의 매우 낮은 소리 기준(0.0005)을 0.003으로 높여 조용한 세션의 이름이 후보에 끼는 것을 줄였습니다. 자신의 PID와 자식 프로세스는 제외합니다. 이 기준은 출처 이름에만 적용하며, 자막용 원래 음성을 잘라내거나 인식을 중단하지 않습니다. 아주 조용한 실제 음성은 이름 없이 자막이 나올 수 있습니다.

한 자막 구간의 유효 관측 시간 중 최소 80%에서 같은 출처가 확인되어야 이름을 표시합니다. 잠깐의 알림음은 주 출처를 바꾸지 않지만, 지속적인 겹침과 서로 다른 앱으로 바뀌는 구간에서는 이름을 비웁니다. 음성 인식 초안이 완성되면서 출처 증거가 늘면 이름이 바뀌거나 없어질 수 있습니다.

이 기능은 **재생 앱 활동과 음성을 시간으로 대응하는 기능**입니다. 출력에 섞인 각 사람의 음성을 분리하거나, 배경 음악과 말 중 어느 소리가 발화인지 정확히 판별하는 기능은 아닙니다. 겹친 음성의 화자를 정확히 분리했다고 주장하지 않습니다. 정확한 웹사이트 이름은 기존의 선택적 브라우저 확장이 필요합니다.

## 검증

- 106개 회귀 검사 통과. 활성이나 열린 세션만으로 출처를 표시하지 않음, 음소거·0볼륨·무음·낮은 소리·앱 자신의 세션과 자식 제외, 여러 출처 합치기 제거, 사이트 정보만으로 출처 생성 금지, 오래된 출처가 이후 무음에 남지 않음 등을 확인했습니다.
- Windows COM 세션 인터페이스를 사용하는 제어된 시험에서 여러 열린/무음/음소거/자기 프로세스 중 실제 유효 재생 후보만 선택하는지 확인했습니다.
- 실제 Windows에서 소리 수집을 열어 검사했습니다. 자신의 Python 재생 장치 세션이 목록에 나타나는 것을 확인했고, 전후 포함 8회 검사에서 유효 출처 후보는 0건, 기술적인 앱 이름 표시도 없었습니다. 당시 실제 유효 재생 소리가 없는 상태의 검사이며, 여러 실제 앱의 동시 발화를 재생한 시험은 아닙니다. 시험 음성은 저장하거나 소리로 재생하지 않았습니다. [수치 증거](evidence/source-probe-v091.json)
- Qt 화면에서 출처가 없는 자막은 헤더를 숨기고, 확인된 VLC·YouTube 출처는 다시 표시하는지 검사했습니다. 출처가 불분명한 자막에 Discord 닉네임이 기록되지 않는지도 확인했습니다.
- 실제 새 EXE 설치와 실제 Whisper 음성 인식·NLLB 번역·기존 자막·Discord/사이트 확장 모의 연동 검사를 수행했습니다. 사용자 계정의 실제 Discord 통화와 다중 앱 음성을 끝까지 분리한 검사는 아닙니다.

언어 선택·같은 언어 숨김·반투명 두 줄 자막은 유지합니다. 모델은 Whisper large-v3-turbo와 NLLB-200 distilled 600M이며, 번역 모델은 **무료 개인·비상업용(CC-BY-NC-4.0)**입니다. 최초 온라인 설치에는 인터넷과 수 GB 공간이 필요합니다. 기존 앱을 닫고 같은 위치에 설치하면 모델을 재사용합니다.
