# 0.9.4 반복 자막·가독성 수정

Windows 0.9.3 실사용 녹화에서 말하지 않은 감사 인사가 반복되고, 임시 번역이 문장 앞부분부터 자주 바뀌어 읽기 어려운 문제를 확인했습니다. Android 0.1.0 APK는 이번 변경 대상이 아닙니다.

## 바뀐 동작

첫 번역은 빠르게 표시하되, 말하는 중에는 이미 보이는 문장을 유지합니다. 기존 글에 이어 붙일 수 있는 내용만 추가하고, 말이 끊겨 최종 결과가 오면 문장 전체를 바로 고칩니다. 긴 발화 중 번역의 어순이 계속 달라지면 임시 자막을 자주 바꾸는 대신 최종 확인을 기다립니다. 이전 문장 표시도 유지합니다.

아주 짧은 임시 결과는 최종 인식까지 기다립니다. 짧은 소리만 듣고 모델이 상투적인 문구를 추측하는 경우를 줄이기 위한 일반적인 길이 기준입니다. 특정 감사 인사를 금지어로 삭제하거나 반복되는 실제 말을 무조건 지우지 않습니다.

WebRTC가 잡아낸 음성 후보를 Silero로 한 번 더 확인한 뒤 임시·최종 인식에 보냅니다. 원래 오디오와 화자용 시각은 바꾸지 않습니다. 음성 검사 모델은 기존 faster-whisper에 포함된 것을 사용하며 별도 대형 모델을 추가하지 않습니다. 준비 과정에서 예열합니다.

두 단어짜리 결과가 매우 짧은 음성 조각에서 나왔고, 언어 판별과 내용 단어의 신뢰도까지 함께 낮을 때는 보류합니다. 한 단어 호출, 충분한 음성 길이, 신뢰도가 높은 짧은 문장은 이 조건에서 제외합니다. 반대로 아주 짧고 불분명한 실제 말이 누락될 수 있는 한계도 있습니다.

최종 결과가 비거나 음성 근거가 없으면 해당 구간의 임시 자막을 회수합니다. 늦게 끝난 번역이 다시 나타나지 않게 하며, 다른 구간의 정상 자막은 남깁니다. 기존에는 빈 최종 결과가 임시 자막을 취소하지 않아 잘못된 글이 남을 수 있었습니다.

## 검증 범위

- 사용자가 제공한 약 6분 녹화 중 실제 통화 구간 약 270초를 로컬에서 처리했습니다. 원본 영상·음성·개인정보·대화 전문은 저장소에 포함하지 않았습니다.
- 수정 전후 같은 Whisper large-v3-turbo 가중치와 GPU int8_float16 설정을 사용했습니다. 모델 재학습이나 더 큰 음성 모델로 교체한 작업은 아닙니다.
- 빠른 초안과 최종 결과를 모두 순서대로 처리한 오프라인 재현입니다. 실제 실행에서는 늦은 초안을 버리므로, 인식 갱신 수를 실제 화면 표시 횟수나 발화 횟수로 해석하면 안 됩니다. 전체 정확도 점수도 아닙니다.
- 새 자동 검사 14개를 포함해 140개 회귀 검사를 통과했습니다. 실제 Qt 화면 코드를 화면에 창을 띄우지 않고 실행해 초안 회수, 늦은 번역 차단, 정상 감사 인사 표시, 확정 전 문장 유지도 확인했습니다.
- 직접 작성해 합성한 감사 인사·호출과 기존 자체 작성 예문을 정상 음량 및 약 30dB 낮춘 조건에서 확인했습니다. 작은 음량 시험은 모든 억양·발음·소음에서의 보장을 뜻하지 않습니다.

재현에서 감사 인사 계열 인식 갱신은 **61→3회**, 최종 확정 결과의 해당 문구는 **3→0회**, 말이 거의 없는 검사 구간의 글자는 **5→0회**였습니다. 남은 3회는 중간 초안이며 모든 오인식이 없어진 것은 아닙니다. 직접 작성한 정상·약 30dB 작은 음량 대조 18조건과 짧은 감사 인사·호출 4조건을 통과했습니다. 무인 설치 종료 코드 0, 실제 설치 소스 일치, 설치된 코드의 실제 Whisper/NLLB 검사도 통과했습니다. 기존 시험 환경과 모델을 재사용한 검사이며 Python이 없는 새 PC 최초 설치 시험은 아닙니다.

최종 재현 수치와 설치 검사 결과는 [검증 JSON](evidence/quiet-readability-v094.json)에 기록합니다. 텍스트 번역 및 화면 갱신 규칙을 고쳤지만, 모든 단어 오인식과 의미 오류가 없어졌다는 뜻은 아닙니다. 1.4초 이내 표시를 새로 보장하거나 단어를 들을 때마다 완벽히 번역한다고 주장하지 않습니다.

## 업데이트

기존 앱을 닫고 `UniversalVoiceKR_Setup_v094.exe`를 실행해 기존과 같은 위치를 선택합니다. 현재 받은 모델을 재사용할 수 있습니다. 가독성 변경과 잡음 검사에는 별도 설정이 필요 없습니다.
