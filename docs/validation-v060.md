# 0.6 검증 기록

2026-10-17, Windows / RTX 4050 Laptop 6 GB / faster-whisper 1.2.1 / CTranslate2 4.8.3 / Whisper large-v3-turbo, GPU int8_float16. 확정 문장은 beam 5, 임시 문장은 beam 1을 사용했습니다.

## 실시간 표시

준비된 모델에 녹음을 실제 재생 속도로 50ms씩 공급하고, 음성 입력 시작부터 화면에 전달할 자막 이벤트까지 측정했습니다. 준비·다운로드 시간은 제외했습니다. 실제 Discord 통화, 장시간 게임 부하 또는 서로 겹쳐 말하는 여러 사람을 시험한 값은 아닙니다.

| 첫 짧은 자막 | 언어 직접 선택 | 자동 언어 감지 |
|---|---:|---:|
| 한국어 음성 → 한국어 표시 | 0.859초 | 1.109초 |
| 영어 음성 → 원문 표시 | 0.828초 | 1.094초 |
| 영어 음성 → 한국어 번역 표시 | 0.875초 | 1.110초 |

첫 짧은 자막은 ‘적들이’, ‘They are → 그들은’ 같은 일부 구절입니다. 전체 문장의 번역이 이 시간에 확정된다는 뜻은 아닙니다. 약 0.5초 분량에서 초안을 시작하고 이후 약 0.4초 단위로 지금까지 들은 말을 다시 인식·번역합니다. 앞의 번역은 뒤에 들린 말에 따라 바뀔 수 있습니다. 말을 끝내거나 대화 중 1초 이상 쉬어야 할 필요는 없습니다.

별도의 전체 녹음 비교에서 0.5.2는 첫 한국어 표시가 3.734초, 영어→한국어 표시가 2.531초였습니다. 같은 시험의 0.6은 각각 0.828초와 0.843초였습니다. 반복 실행마다 차이가 있습니다. 첫 1.4초 이내 표시를 목표로 조정했지만 CPU 사용, GPU 부하, 낮은 소리, 불분명한 발음, 미지원 번역 언어 등에서는 더 늦어질 수 있습니다. 지연에 상한을 보장하는 구조는 아닙니다.

## 확정 인식 정확도

동일한 한국어·영어 합성 음성을 일반, 약 -30dB, 1.45배 빠른 말, 대역 제한+빠른 말+소음 조합으로 변형하여 비교했습니다. 한국어는 문장부호·공백을 제외한 문자 오류율(CER), 영어는 단어 오류율(WER)입니다. 이는 작은 시험 모음이며 실제 대화 전체의 정확도를 의미하지 않습니다.

| 시험 | 0.5.2 | 0.6 |
|---|---:|---:|
| 한국어 일반 / 작은 소리 / 빠른 말 CER | 0% / 0% / 0% | 0% / 0% / 0% |
| 영어 일반 / 작은 소리 / 빠른 말 WER | 0% / 0% / 0% | 0% / 0% / 0% |
| 한국어 대역 제한+빠른 말+소음 CER | 17.02% | 17.02% |
| 영어 대역 제한+빠른 말+소음 WER | 0% | 0% |

최종 문장을 너무 일찍 끊는 설정은 실제 억양 자료에서 오류율이 높아져 채택하지 않았습니다. 대신 초안을 일찍 보여 주고 확정 인식에는 기존 문장 문맥을 유지했습니다. 모델 가중치를 재학습하거나 모든 발음의 정확도를 높였다고 주장하지 않습니다. 등록한 이름·용어는 선택적으로 인식을 돕지만, 왜곡된 소리를 복원하거나 오인식을 항상 막지는 못합니다.

## 동작 검사

Speech Accent Archive의 실제 억양 녹음을 영어로 직접 지정해 스트리밍 확정 인식을 비교했습니다. 한국어 모어 화자 `korean1`의 WER는 두 버전 모두 17.39%, 스페인어 모어 화자 `spanish1`은 모두 4.35%였습니다. 최종 분할 설정을 유지한 뒤 정확도 저하가 없음을 확인한 작은 비교이며, 모든 발음의 성능을 대표하지는 않습니다. 자료 출처: https://accent.gmu.edu/samples/korean1/ 및 https://accent.gmu.edu/samples/spanish1/ (CC BY-NC-SA 4.0). 해당 음성 파일은 재배포하지 않았습니다.

- 자동 회귀 검사 50개 통과: 짧은 발화, 긴 발화의 겹침, 침묵 필터, 화자 변경, 공식 콜백 처리, 최신 초안 1개 유지, 오래된 번역이 최신 자막을 덮지 않는 순서, 번역 캐시가 반복해서 말한 문장을 누락하지 않는지 검사 등.
- 설치 프로그램의 내역 창 닫기/다시 열기 30회, 닫힌 동안 로그 갱신, 진행 표시 및 창 종료 후 콜백 검사.
- 별도 설치 검증 환경의 GPU 인식, 로컬 번역, 7개 화면 전환, 1000×740 창 크기, 임시 문장과 확정 기록 구분, Discord WebEngine 모의 화면 검사.
- 실제 Discord 계정 연결과 여러 참여자의 실시간 발화 대응은 사용자가 공식 연결을 완료해야 하므로 이 개발 시험에서 수행하지 않았습니다.

로컬 Argos 번역은 일부 일반 문장도 잘못 번역할 수 있습니다. 위의 음성 인식 오류율은 번역의 의미 정확도 점수가 아닙니다.

## 재현

`tools/Make-SpeechFixtures.ps1`로 Windows SAPI Heami/Zira 시험 음성을 만들 수 있습니다. 다음 명령으로 구버전과 신버전의 전체 녹음 지연 및 확정 인식을 비교합니다. 해당 설치 폴더의 모델과 번역 패키지가 준비되어 있어야 합니다.

```powershell
.\tools\Make-SpeechFixtures.ps1
python -B -X utf8 .\tools\benchmark_latency.py '<검증할 설치 폴더>' .\tools\fixtures
```

기본 자료는 자체 합성 음성이며 실제 사용자 통화와 자격증명은 저장소에 포함하지 않았습니다.
