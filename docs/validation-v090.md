# Universal Voice KR 0.9.0 — 언어 선택과 같은 언어 숨김

[새 Windows 설치 파일](https://raw.githubusercontent.com/rys070425-design/sexy-giga-s-voice/main/dist/UniversalVoiceKR_Setup_v090.exe) · [English guide](quickstart-en.md)

설치 창은 영어로 시작합니다. **Language → 한국어**를 선택하면 설치 안내가 바로 한국어로 바뀌고, 설치 후 앱 UI와 모든 저장 프로필의 자막 언어가 한국어가 됩니다. 다른 나라의 언어도 같은 방식입니다. 기존 앱을 닫고 같은 설치 위치를 선택하면 모델을 재사용하며, 다른 프로필 값과 용어 사전은 유지합니다. 최초 설치에는 인터넷과 수 GB의 공간이 필요합니다.

## 선택할 수 있는 언어

기존 언어팩 목록의 25개 선택지를 그대로 사용합니다.

한국어, English, Español, Português, Português (Brasil), Русский, Polski, Türkçe, Deutsch, Français, 中文（简体）, 日本語, Italiano, العربية, Українська, Nederlands, Bahasa Indonesia, हिन्दी, Čeština, Svenska, Tiếng Việt, ไทย, Filipino, Română, فارسی.

브라질 포르투갈어는 포르투갈어 번역 모델과 UI를 공유합니다. 총 24개의 기본 번역 언어입니다. 지원 언어 목록에 없는 언어를 임의로 추가하지 않았습니다. 한국어 원문 UI와 영어 주요 화면을 검토했으며, 다른 언어와 일부 보조 문구는 기계 번역입니다. 모든 나라의 원어민 검수를 마쳤다는 뜻은 아닙니다.

## 같은 언어의 말은 표시하지 않음

설치 시 **표시 언어와 같은 말은 자막·기록에서 제외**가 켜집니다.

| 자막 언어 | 들리는 말 | 처리 |
|---|---|---|
| 한국어 | 한국어 | 자막과 기록에 표시하지 않음 |
| 한국어 | 영어 등 다른 지원 언어 | 한국어로 번역 |
| English | 영어 | 자막과 기록에 표시하지 않음 |
| English | 한국어 등 다른 지원 언어 | 영어로 번역 |

음성에서 언어를 알아낸 다음, 같은 언어라면 텍스트 해독·단어 정렬·번역을 건너뜁니다. 늦게 도착한 이전 번역이 숨긴 자막을 되살리거나 기록에 들어오지 않게 막습니다. 언어 판별용 음성 처리와 모델 메모리는 남습니다. 첫 외국어 자막을 빠르게 표시하도록 번역 모델도 미리 준비하므로 리소스 사용량이 0이 되는 기능은 아닙니다.

이 기능이 켜져 있으면 음성 언어는 자동 감지입니다. 짧은 말·특이한 발음·겹친 음성·한 문장 안에 섞인 언어는 잘못 판별할 수 있습니다. 영어 영상에서 영어 원문 자막을 보고 싶다면 이 항목을 끄고 음성 언어를 English로 고르면 됩니다.

앱 오른쪽 위 **Language**를 바꾸면 화면과 현재 프로필의 자막 언어가 바뀝니다. 프로필별 **표시 언어**는 따로 설정할 수 있습니다. 실행 중 UI 언어를 바꾸면 엔진을 안전하게 다시 시작합니다. 실제 대화 내용·닉네임·사이트·사용자 입력값은 UI 번역으로 변경하지 않습니다.

## 실제 검증

2026-10-17, Windows, i7-13700H / RTX 4050 Laptop 6GB, Whisper large-v3-turbo int8_float16, NLLB-200 distilled 600M CPU int8로 검사했습니다.

- 100개 회귀 검사 통과: 언어팩 목록 일치, 설정 적용, 포르투갈어 별칭, 같은 언어의 지연 텍스트 해독 미실행, 번역·용어 처리 건너뛰기, 늦은 번역 방지 등.
- 설치 창 25개 선택지 전환과 언어별 저장 설정 검사 통과. 영어로 시작하고 한국어로 즉시 전환되는 것을 실제 화면으로 확인했습니다. 영어·한국어·일본어·아랍어 화면을 검토했습니다.
- 실제 EXE를 독립 시험 폴더에 설치하여 한국어와 영어 선택이 UI·모든 프로필의 자막 언어·자동 감지·숨김에 적용되는지 확인했습니다. 기존 구성요소가 있는 시험 설치의 업그레이드이며 새 PC 전체를 초기화한 검사는 아닙니다.
- 설치된 앱의 7개 페이지, 실제 음성 인식·NLLB 번역·자막·Discord 모의 연결·사이트 확장 모의 연결 검사를 통과했습니다. 실제 사용자 Discord 통화와 브라우저 확장을 끝까지 연결한 검사는 아닙니다.
- 설치 로그 창 30회 닫기/재열기와 닫은 뒤 비동기 출력, 설치 중복 실행 방지, 취소, 잘못된 위치, 버퍼 정리, 창 해제 검사 통과. 이전 TextBox 오류 회귀 검사를 포함합니다.
- 25개 언어 선택지 모두 실제 NLLB 지원 경로와 비어 있지 않은 번역 출력을 확인했습니다. 모든 언어의 번역 정확도를 평가한 점수는 아닙니다.

직접 만든 한국어·영어 음성을 실제 시간 간격으로 공급하고 Qt 화면 그리기까지 측정했습니다. 모델 예열 후 파일 시작부터 첫 자막 렌더링까지이며, 실제 Discord 통화 지연이나 번역 확정 시간의 보장은 아닙니다.

| 입력 → 자막 | 조건 | 첫 자막 | 표시 갱신 수 |
|---|---|---:|---:|
| 영어 → 한국어 | 일반 | 1.203초 | 4 |
| 한국어 → 영어 | 일반 | 1.359초 | 4 |
| 한국어 → 한국어 | 같은 언어 숨김 | 표시 안 함 | 0 |
| 영어 → 영어 | 같은 언어 숨김 | 표시 안 함 | 0 |
| 영어 → 한국어 | 1.25배 빠른 말 | 1.250초 | 3 |
| 영어 → 한국어 | 10dB 잡음 | 1.204초 | 4 |

영어 자막의 첫 외국어 번역에서 모델을 늦게 불러오던 부분을 발견했습니다. 자동 감지에서 출력이 영어일 때도 외국어 번역을 미리 준비하도록 고쳤고, 재측정에서 한국어→영어 첫 자막은 2.391초에서 1.359초로 줄었습니다. 단일 PC·작은 합성 자료의 재실행 비교이며 전체 성능 향상률로 일반화하지 않습니다.

자동 언어 감지에는 비용이 있고, CPU·게임 부하·긴 문장·억양에 따라 지연이 늘어납니다. 기존 CPU 시험은 1.4초를 달성하지 못했습니다. 모든 상황의 1.4초 이내를 보장하지 않습니다. [이전 실제 억양·CPU·모델 비교](model-choice.md), [0.8.2 인식 개선](validation-v082.md).

## 유지한 것과 제외한 것

별도 국가별 거대 번역 모델을 추가로 설치하지 않고 기존 공용 NLLB 모델을 재사용합니다. UI 번역은 파일에 담아 배포하며, 화면 메뉴를 바꿀 때 AI 모델이나 유료 API를 호출하지 않습니다. 기존 원문 자막 기능은 학습용 사용자를 위해 옵션으로 유지하지만 기본값에서는 같은 언어의 자막·기록을 제외합니다.

음성 모델 가중치를 새로 학습하지 않았습니다. Whisper와 NLLB는 오인식·오역이 남으며, NLLB는 **CC-BY-NC-4.0 개인·비상업용**입니다. 선택 기능인 ChatGPT 보정은 별도 로그인과 이용 조건이 적용됩니다. [모델·라이선스 안내](third-party.md).
