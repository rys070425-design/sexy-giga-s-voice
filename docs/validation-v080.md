# 0.8 · 번역 품질과 읽기 안정성

## 실제 바뀐 모델

음성 인식은 기존 Whisper large-v3-turbo / faster-whisper를 유지합니다. 이번에 교체한 것은 인식 뒤의 **번역 모델**입니다. 기본 번역을 오래된 Argos 영어→한국어 모델에서 **NLLB-200 distilled 600M, CPU int8**로 바꿨습니다. 모델을 새로 학습한 것은 아닙니다.

직접 작성한 영어 일반 문장 20개와 추가 부정·숫자 문장, 7개 번역 대상 언어의 긍정/부정 문장을 실제 모델로 비교했습니다. 예를 들어 기존 모델은 “I disagree with that idea.”를 동의한다는 뜻으로, “Please close the door.”를 FAQ라는 뜻으로 번역했습니다. 선택한 NLLB 모델은 각각 “동의하지 않습니다”, “문 닫으세요”로 번역했습니다. 가게 영업 종료 시각과 ‘내일 오지 않아도 된다’는 표현도 비교했습니다.

M2M100도 실제 비교했지만 일부 일본어 부정문과 한국어 의무 표현을 잘못 번역해 기본 모델 후보에서 제외했습니다. NLLB에도 오역은 남아 있습니다. 짧은 “Turn left.”를 잘못 번역한 사례가 있었고, 모든 언어·억양·상황에서 정확하다는 뜻은 아닙니다. 평가 문장 정답을 사전에 넣어서 결과를 바꾸지 않았습니다.

모델 가중치와 토크나이저는 [Meta 공식 배포](https://huggingface.co/facebook/nllb-200-distilled-600M)를 사용합니다. 기본 번역 모델은 **CC-BY-NC-4.0, 비상업용**입니다. 무료 개인 대화·영상 자막 용도로 준비했습니다. 모델 원문 라이선스와 출처·양자화 변경 정보는 배포 자료에 포함됩니다. 원본 모델은 연구용이며 공인 번역을 제공하지 않습니다.

## 첫 화면에 실제로 보인 시간

RTX 4050 Laptop GPU에서 자체 합성 음성을 50ms씩 실제 시간으로 공급했습니다. 모델 준비 시간 이후, 입력을 공급한 시점부터 첫 **Qt 자막의 offscreen 렌더링 완료**까지 측정했습니다. 실제 자막 위젯의 글꼴·줄바꿈·그림자를 적용한 검사이며, 모니터의 물리적인 표시 시간을 측정한 것은 아닙니다. 외국어 원문이 먼저 잠깐 나타난 시각을 번역 시간으로 계산하지 않았습니다.

| 입력 / 표시 | 첫 표시 |
|---|---:|
| 영어 고정 → 한국어 | 0.907초 |
| 영어 자동 감지 → 한국어 | 1.171초 |
| 한국어 고정 → 한국어 | 0.781초 |
| 한국어 자동 감지 → 한국어 | 1.250초 |
| 영어 1.25배속 → 한국어 | 0.953초 |
| 영어 + 10dB 잡음 → 한국어 | 0.922초 |
| 영어 → 영어 원문 자막 | 0.812초 |

이 시험의 7개 조건에서는 첫 렌더링이 1.4초 이내였습니다. 각 조건 1회 측정이며 실제 Discord·YouTube 소리, CPU 환경, 모든 발음의 보장 시간이 아닙니다. 첫 표시는 문장 전체가 완성되기 전의 초안입니다. 갱신 결정 간격은 최소 0.812초, 렌더링 완료 사이의 간격은 최소 0.797초였습니다. 더 빠른 인식 결과를 매번 덮어써서 깜빡이지 않게 했습니다. 번역 추론 자체는 짧은 일반 문장에서 준비 후 대체로 약 0.14~0.37초였습니다.

음성 인식 설정·최종 분할 길이는 이전 정확도 시험 조건을 유지했습니다. 어려운 발음과 빠르고 뭉개진 음성의 기존 시험은 [0.6 검증](validation-v060.md)을 참고하세요. 이번 변경을 음성 모델 재학습이나 실제 사용자 통화 발음 평가로 표현하지 않습니다.

## 사용 방법

1. 기존 앱과 설치 프로그램을 닫고 0.8 설치 파일을 실행합니다. 기존 설치가 없어도 설치할 수 있습니다. 기본 번역 모델 자료 약 582MB를 추가로 받으며, 이미 받은 음성 모델은 확인 후 재사용합니다.
2. 첫 화면에서 재생 출력 장치, **음성 언어 / Speech**, **표시 언어 / Captions**를 선택하고 **Start**를 누릅니다.
3. 영어를 듣는 사용자는 한국어·English·Español·Français·Deutsch·日本語·中文·Português 중 표시 언어를 고를 수 있습니다. 영어 원문 자막에는 번역이 필요하지 않습니다. 공용 번역 모델이 지원하는 방향은 별도 언어별 모델을 다시 받지 않습니다.
4. 프로필의 배경 진하기는 기본 42%, 범위 15~80%입니다. 변경은 즉시 보이고 자동 저장됩니다. 직접 입력한 출처 이름도 입력을 마치면 저장됩니다.
5. **기록 저장 / Save**로 현재 남아 있는 원문과 번역을 텍스트로 저장해 복습할 수 있습니다. 자동 저장이나 음성 녹음은 하지 않습니다. 오래된 기록은 메모리 제한 때문에 정리되므로 전체 통화의 녹취 파일을 보장하는 기능은 아닙니다.

For English listeners: choose your playback device, select English under Speech, choose the caption language, then press Start. Translation runs on this PC. The bundled translation model is for noncommercial use. The rest of the interface is primarily Korean; this is not a fully localized English interface.

## 안정성 수정과 정리한 기능

- 이전 줄의 늦은 확정 번역은 이전 줄만 고칩니다. 최신 문장을 과거로 되돌리지 않습니다.
- 아직 번역되지 않은 원문이 도착했다고 이미 처리 중인 번역을 버리지 않습니다.
- 같은 음성 구간에서 화자가 바뀌는 경우 두 사람의 문장을 단순 수정본으로 취급하지 않게 했습니다.
- 재생 앱이 바뀌는 구간과 여러 소리를 특정 Discord 닉네임에 단정해서 붙이지 않습니다.
- 앱을 두 번 실행하면 기존 창을 엽니다. 음성 모델을 두 개 올려 GPU 메모리를 낭비하지 않습니다.
- 창의 시작 크기를 작업 화면에 맞추고 최소 960×620에서 안내를 스크롤해 볼 수 있게 했습니다. 긴 언어 선택 항목 때문에 화면 폭이 늘어나지 않게 했습니다.
- 전체 화면 스타일에 묻혀 자막 글자 크기가 작아지던 문제를 시각 검사에서 찾아 고쳤습니다. 긴 출처 이름도 자막 본문을 밀어내지 않게 줄여 표시합니다.
- Discord PC 앱이 닫혀 있을 때 짧은 화면 갱신마다 재연결을 시도하지 않고 간격을 둡니다. 설치 프로그램의 중복 실행·취소·잘못된 설치 경로와 설치 내역 창 닫기 동작도 보완했습니다.
- 매번 원문/번역을 교차 표시하는 동작, 알 수 없는 화자·인식 중 상태의 반복, 같은 원문의 중복 표시는 읽기를 방해해 정리했습니다.
- 유료 실시간 번역 자동 호출, 전면 웹사이트를 음원으로 추측하는 기능, 읽을 수 없는 속도로 모든 초안을 표시하는 옵션은 추가하지 않았습니다.

## 검증 범위

자동 회귀 검사 88개, 별도 설치 환경의 GPU 인식·실제 NLLB 번역·7개 화면·최소 창 크기·두 줄·투명도·자동 저장·중복 실행 방지 검사를 통과했습니다. NLLB의 가벼운 실행 경로가 Transformers 토크나이저로 얻은 26개 비교 결과와 일치하며, 앱에 Torch/Transformers를 불러오지 않는 것도 확인했습니다.

합성 입력을 실제 시간으로 약 6분 29초 공급하면서 빠른 말·작은 소리·잡음을 섞어 3회 시작/종료했습니다. 확정 문장 144개를 처리했고 대기열 초과나 작업 중지 실패는 없었습니다. 각 회차 종료 후 프로세스 메모리는 741.7 / 742.8 / 749.2MB였습니다. 이 짧은 반복 시험에서 큰 누적 증가는 관찰하지 않았으며, 수 시간 통화의 메모리 보장 시험은 아닙니다. 설치 파일 자체의 silent 설치와 빈 폴더에서 공개 모델 주소의 무인증 다운로드·개별 파일 무결성 확인도 통과했습니다.

Discord 현재 통화방 자동 조회와 Chrome/Edge 확장은 모의 공식 응답/브라우저 API로 검사했습니다. 실제 사용자 계정 승인, 실제 통화방 이동, 사용자 브라우저에 확장 설치까지 대신 수행한 것은 아닙니다. 사이트 이름은 선택 확장을 한 번 연결해야 하며, 없이도 재생 앱 이름과 자막은 사용할 수 있습니다. 여러 사람·여러 소리가 겹친 혼합 오디오를 사람별로 분리하는 기능은 아닙니다.
